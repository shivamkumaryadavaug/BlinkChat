# BlinkChat

A premium rebuild of [BlinkChat](https://blink-chat-liard.vercel.app/) — temporary, anonymous group chat, redesigned as an installable app.

**Chat freely. Leave nothing behind.**

## What’s inside

- Cinematic dark UI (Instrument Serif + Outfit) with aurora, grain, and motion
- Create a vanishing room (name, 1h / 6h / 24h / 7d, max people, optional password)
- Join with a `WORD-1234` code, QR, and share link
- Real-time chat: identities, replies, reactions, typing, presence, expiry
- PWA — add to home screen

## Run

```bash
npm install
npm run dev
```

App: `http://localhost:5173`  
API: `http://localhost:8787`

Open two browser windows, create a room in one, join with the code in the other.
